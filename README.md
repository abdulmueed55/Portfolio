# Abdul Mueed — Portfolio

Personal portfolio for Abdul Mueed, a WordPress, WooCommerce, PHP/Laravel and modern frontend developer.

The site is prepared for GitHub Pages. A custom domain can be connected later from the repository's Pages settings.

## Deployment

GitHub Pages publishes the static portfolio from the repository root on the `main` branch.

## Contact form

The GitHub Pages contact form uses FormSubmit's AJAX endpoint and delivers enquiries to Abdul's email inbox. `contact.php` is retained for PHP hosting when the custom domain is moved to the final server.
